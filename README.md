# CampusBite - Campus Food Pre-Order System

React/Vite starter UI for a university Web Development project.

## Run

```bash
npm install
npm run dev
```

Open the local URL shown by Vite.

## Demo routes

- `/` Landing page
- `/login`
- `/register`
- `/canteens`
- `/canteens/1/menu`
- `/cart`
- `/orders`
- `/staff`
- `/admin`

## Current state

This version uses mock data only. The next stage is connecting it to a Spring Boot REST API and MySQL database.
